# AI suggestions for DataFlow

These eight ideas came from AI brainstorming and are open for discussion.

1. **Explain where a number comes from.** Select a value in a chart to see the calculation behind it and, where possible, the source rows that contributed to it.
2. **Show how changes affect results.** Compare versions to see changes to data, calculations, and canvas layout. Alongside the code diff, show how many rows a new filter removed and how that changed total revenue.
3. **Create and compare scenarios.** Try a variation, such as a 10% increase in purchase prices, and compare the results side by side. Use scenarios without learning Git.
4. **Define and check what each block accepts.** A block could require a table with a date column and a currency amount. Show clear messages at the connection when a column is missing, a key is duplicated, or a value uses the wrong currency.
5. **Combine visual editing with code.** Filter, group, and connect data with visual controls. Open the calculation in a code editor when you need more control. Show which changes the visual editor can still represent.
6. **Share an interactive report.** Put selected tables, charts, and controls in a report. Readers can adjust the parameters you share from the report itself.
7. **Show whether a result is current.** Display the input data version, component version, and whether the result is current, out of date, or the latest run failed. If you still show a result from an earlier run, label it with its original date.
8. **Work locally and offline.** Edit personal analyses and sensitive data on your device. Add syncing and shared catalogs on top of local work.

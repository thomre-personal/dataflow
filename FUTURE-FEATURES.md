# Future features for DataFlow

These ideas are for later product planning. Their scope is open.

## Financial data

Let users bring financial data into a canvas as an input for calculations, charts, and reports.

The first proposal covers stock search, instrument details, daily closing
prices, and currency conversion. See [data connectors](DATA-CONNECTORS.md) for
the API comparison and other source ideas. Historical prices are in the
[DataFlow TODO list](TODO.md).
